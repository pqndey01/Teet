# Meri Website

Simple, mobile-friendly website (HTML + CSS + JS). Kisi build ya install ki zaroorat nahi.

## Files
- `index.html` - main page
- `style.css` - design
- `script.js` - menu, animation, form
- `404.html` - error page
- `.nojekyll` - GitHub Pages ko batata hai ki files jaisi hain waisi serve karo

## GitHub Pages par host karne ke steps
1. ZIP ko pehle **extract** karo (GitHub ZIP ko khud extract nahi karta).
2. github.com par naya repository banao (Public).
3. **Add file -> Upload files** par jao aur extract hui saari files upload karo (`index.html` repo ke root mein hona chahiye).
4. **Commit changes** dabao.
5. **Settings -> Pages** kholo.
6. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** chuno aur **Save** karo.
7. 1-2 minute baad link milega: `https://USERNAME.github.io/REPO-NAME/`
